1. 성취기준 고르기

고등학교는 이 앱에 핵심아이디어 자료가 없어 성취기준·성취수준만으로 만듭니다.

2. 개념 정하기

미리 작성한 검토용 사례입니다. 실제 학생 진단이나 AI 생성 결과가 아닙니다.

성취기준 하나를 고르면, 교육과정 원문을 옆에 두고
학생이 어디서 헷갈릴지와 그때 무엇을 물을지를 함께 만듭니다.

  1. 왼쪽에서 성취기준을 고릅니다.
  2. 성취기준·성취수준·핵심아이디어 원문을 확인합니다.
  3. 개념을 정하고 오개념·발문 지도를 만듭니다. 이 성취기준을 다루는 여러 차시에서 발문 카드로 씁니다.
  4. 카드 하나를 골라 검토·수정하고 새 사례 확인 질문과 적용 계획을 남깁니다. 차시안은 선택입니다.

탑재 자료를 표시합니다. 공식 문서의 판본·쪽수는 별도 확인이 필요합니다. 낮은 수준의 서술에 없는 능력을 곧바로 결손으로 해석하지 마세요.

      개념 한 걸음 사용법

      1. 성취기준 고르기 — 학교급·학년군·교과·영역에서 고르거나 낱말로 찾습니다.
      2. 근거 확인 — 성취기준·성취수준(최하 수준은 붉게)·핵심아이디어 원문이 옆에 뜹니다. 전체 성취수준을 비교하되, 원문과 오개념 가설을 구별합니다.
      3. 개념 정하기 — 「개념 후보 추천」을 누르거나 직접 입력합니다.
      4. 오개념·발문 지도 만들기 — 도입 방식 판단, 개념 정의, 예상 오개념 최대 3개(진단 질문·교정 발문·발문 트리·확인·쓰는 장면)가 나옵니다.
      5. 검토하고 고치기 — 검토 4항목을 보며 모든 칸을 클릭해 고칩니다. 한 카드를 골라 수정·유지·보류 이유와 적용 계획을 기록하세요. API 연결이 어려우면 키 없이 연습하거나 직접 작성합니다.
      6. 차시안(선택) — 개념을 처음 도입하는 차시라면 귀납 또는 연역-후-범례 방식 차시안을 추가로 만듭니다. 예시·비예시 제시 모드로 화면에 띄울 수 있습니다.
      7. 수업 뒤 — 오개념 카드마다 「실제로 나왔다 / 관찰하지 못했다 / 확인 기회 없음」를 표시하고 메모를 남겨 저장하면, 저장 목록에서 해당 지도를 다시 열어 관찰 기록과 예측을 비교합니다.
