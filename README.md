# 개념 한 걸음

2022 개정 교육과정 자료를 옆에 두고 「오개념·발문 지도」의 가설을 만들고 검토하는 교사용 도구입니다. 성취수준은 수행의 도달 정도를 나타내며, 실제 오개념의 발생·원인을 진단하지 않습니다.

## 올리는 방법 (GitHub Pages)
1. GitHub에 새 저장소를 만들고 이 폴더의 파일을 그대로 올립니다. (index.html, app.js, practice.js, style.css, data/)
2. Settings → Pages → Branch를 main / (root)로 두고 저장합니다.
3. 잠시 뒤 `https://아이디.github.io/저장소이름/` 에서 열립니다.

## 사용 준비
- API 키 없이 초·중·고 연습 카드를 열거나 선택 성취기준으로 직접 작성할 수 있습니다. 연습 카드는 미리 작성한 사례이며 실제 학생 관찰 자료나 AI 생성 결과가 아닙니다. 최초 페이지·교육과정 자료를 여는 데에는 인터넷이 필요합니다.
- AI 생성은 Google AI Studio(https://aistudio.google.com/app/apikey)에서 발급한 본인 키를 「API 키 설정」에 넣어 사용합니다. 키는 브라우저에 저장되며 요청 시 키와 입력 내용이 Google Gemini API로 전송됩니다. 개인 식별 정보는 입력하지 않습니다. 모델·요금·할당량은 계정에 따라 다릅니다.
- 같은 창의 「이 키로 쓸 수 있는 모델 불러오기」를 누르면 현재 계정에서 쓸 수 있는 Gemini 모델 목록이 나옵니다. 새 모델이 나와도 앱을 고칠 필요 없이 고르면 됩니다.

## 연수 검토 반영(9/19)
- 원문 출처·인용과 예상 가설·대안 설명을 분리합니다. 인용을 해당 탑재 원문과 대조하지만, 공식 자료의 판본·쪽수나 오개념의 타당성까지 검증하는 기능은 아닙니다.
- 원인 유형의 중복과 판단 보류를 허용합니다. 유지 반응에는 조작·대조·재표현·짧은 설명 등 다른 지원을 제안하고 새 사례로 확인합니다.
- 카드 하나를 골라 검토 4항목, 수정/유지/보류 이유, 다음 수업 적용 계획을 기록합니다. 카드별 기록과 수정 횟수는 저장·불러오기·복사에 보존됩니다. 체크나 수정 횟수는 내용의 정확성을 인증하지 않으며 저장을 막지 않습니다.
- 선택 카드 인쇄를 추가했습니다. 글을 길게 편집하면 여러 장으로 나뉠 수 있으므로 인쇄 미리보기에서 확인합니다.
- 고등에는 초중 공통교육과정 핵심아이디어를 연결하지 않습니다. A~E 자료에서 C를 일괄적으로 '하'라고 표시하지 않습니다.
- 기존 Gemini 모델을 임의 교체하지 않습니다. 요청 대기시간 제한과 오류 안내를 추가하고, 잘못된 지도 응답은 기존 결과에 적용하기 전에 검사합니다.
- 수업 뒤 '관찰하지 못함'과 '확인 기회 없음'을 구분합니다. 이전 저장 자료도 열 수 있으며, 인용 칸이 없던 자료는 별도 확인을 안내합니다.

## 데이터
- data/standards.json — 탑재 성취기준 2,217개와 성취수준. 현재 데이터는 초등 A~C, 중등 A~E 또는 A~C, 고등 A~E입니다. 이번 수정에서 원문 데이터 자체는 변경하지 않았습니다. 교육과정 전체 과목을 빠짐없이 포함한다는 뜻은 아니며, 공식 출처 문서·판본·쪽수의 별도 대조가 필요합니다.
- data/core_ideas.json — 공통교육과정(초1~중3) 핵심아이디어 46개 영역 153항목
- 초·중 사회·과학처럼 성취기준 영역명이 핵심아이디어 영역명과 다른 교과는 자동 연결 대신 교사가 체크하거나, 비워 두면 AI가 관련 항목을 골라 인용합니다.

## 연수 실습
1. 자기 성취기준을 고르거나 학교급별 연습 카드를 엽니다.
2. 초안을 생성한 경우 최대 3개 중 한 카드를 선택합니다.
3. 원문과 가설을 구별하고 학생의 다른 가능한 이유를 확인합니다.
4. 자료·발문·유지 반응의 지원·새 사례 확인 중 2곳을 검토하고 판단 이유를 기록합니다.
5. 다음 수업 적용 계획을 쓰고 저장합니다. 저장 목록의 「파일」은 JSON 내려받기, 「파일에서 불러오기」는 복원입니다.
